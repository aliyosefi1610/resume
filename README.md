# Ali Yousefi Portfolio

A production-ready Angular portfolio website generated from Ali Yousefi's 2025 resume.

## Stack

- Angular 21
- Standalone components
- TypeScript
- SCSS
- Angular Router
- Signals
- Responsive, mobile-first UI
- Dark and light mode

## Run

```sh
npm install
npm start
```

## Build

```sh
npm run build
```

The resume PDF is available at:

```text
src/assets/resume/ali-yousefi-cv-2025.pdf
```
